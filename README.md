# Gather Plan · 모임 순서표

교회 행사, 수련회, 소그룹 모임의 진행 시간표와 준비물을 정리하는 작은 도구입니다.
설치, 로그인, API 키, 외부 라이브러리 없이 브라우저에서 실행합니다.

이 저장소에는 독립 프로그램만 들어 있습니다. CHRISTIAN VIBE 운영 서비스의 소스는 포함하지 않습니다.

## 실행 방법

1. 이 저장소의 **Code → Download ZIP**으로 내려받고 압축을 풉니다.
2. `gather-plan.html` 파일을 Chrome, Edge, Firefox 또는 Safari에서 엽니다.
3. 행사 이름과 시작 시각을 정하고 순서를 편집합니다.

서버 실행이나 패키지 설치는 필요 없습니다. 초기 예제는 총 100분이며, 14:00에 시작하면 15:40에 끝납니다.

## 기능

- 순서 이름, 소요 시간, 담당자, 준비물 입력
- 순서 추가·삭제·위아래 이동
- 시작·종료 시각 자동 계산, 자정 이후 날짜 표시
- 목표 종료 시각 대비 초과·여유 시간 표시
- 쉼표와 줄바꿈으로 구분한 준비물의 동일 문자열 중복 제거
- 작업 파일(JSON) 저장·불러오기
- 한글 CSV 저장과 인쇄/PDF 저장
- 가능한 환경에서 브라우저 임시 저장

## 사용 안내

- 소요 시간은 각 순서당 1~1,440분, 순서는 최대 200개입니다.
- 목표 종료 시각이 시작보다 이르면 다음 날로 계산합니다. 같은 시각이면 같은 날의 종료 목표입니다.
- 파일 불러오기는 현재 작업을 대체합니다. 중요한 작업은 먼저 JSON으로 저장하세요.
- JSON 가져오기 크기는 최대 2MB입니다.
- 준비물은 정확히 같은 이름만 중복 제거합니다. 수량 합산은 하지 않습니다.
- CSV에서 수식으로 해석될 수 있는 텍스트는 작은따옴표를 앞에 붙입니다.
- 인쇄 창의 저장 대상을 PDF로 선택하면 진행표를 PDF로 저장할 수 있습니다.
- 작은 화면에서는 진행 순서 표를 가로로 스크롤할 수 있습니다.

## 개인정보와 저장

입력 내용을 서버로 전송하는 기능은 없습니다. 네트워크 요청, 외부 글꼴, 분석 도구를 사용하지 않습니다.
브라우저 저장 공간 사용이 허용되면 현재 작업을 임시 저장합니다.
파일로 여는 환경이나 개인정보 보호 모드에서는 임시 저장이 제한될 수 있으므로 JSON 저장을 함께 사용하세요.
공용 컴퓨터에서는 작업 후 저장된 정보와 다운로드 파일을 직접 정리하세요.

## 검증 상태

업로드 전에 JavaScript 구문 검사와 핵심 로직 12개 검사를 실행했습니다.
검사 범위: 자정 이후 시각, 진행 시간 누적, 시간 형식, 준비물 구분, CSV 따옴표·수식 방지, JSON 입력 제한.
브라우저 화면, 다운로드 동작, 인쇄 및 브라우저별 호환성은 아직 직접 검증하지 않았습니다.

## 수동 확인 방법

1. 예제의 예상 종료가 15:40, 목표 대비 20분 여유인지 확인합니다.
2. 시작을 23:50으로 바꾸고 다음 날 종료가 표시되는지 확인합니다.
3. 순서를 추가·이동·삭제한 후 시간과 준비물이 갱신되는지 확인합니다.
4. JSON을 저장하고 다시 불러와 입력 내용이 유지되는지 확인합니다.
5. CSV의 한글과 열 구분을 확인하고, 인쇄 미리보기에서 진행표를 확인합니다.
6. 잘못된 JSON, 0분, 소수 시간 입력이 거절되는지 확인합니다.

## 배포 설정

`vercel.json`의 `git.deploymentEnabled: false`는 이 저장소의 Git 커밋으로 Vercel 자동 배포가 실행되지 않도록 하기 위한 설정입니다.
이 저장소를 기존 운영 사이트에 배포하는 용도로 사용하지 마세요.
별도 웹 호스팅이 필요하면 프로젝트 연결과 도메인을 따로 설정하고 확인해야 합니다.
